# Moonbase

## Language

**Notebook**:
An ordered document containing cells, with any metadata and results its format
can retain. Jupyter notebooks and DIB notebooks are notebook formats.

**Cell**:
A notebook's unit of source content. A cell can contain executable code,
Markdown, raw text or content introduced by a format extension.

**Kernel selector**:
A DIB directive that identifies a registered execution kernel and starts a
new cell. Other directives remain part of a cell's source.

**Output**:
A stored result associated with a code cell. Jupyter notebooks can retain
outputs; DIB notebooks contain source without stored execution results.

**Attachment**:
A named bundle of media representations associated with a cell's source.
